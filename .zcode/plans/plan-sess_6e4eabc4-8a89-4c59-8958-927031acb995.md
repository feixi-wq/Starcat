# 星标曲线「描边生长」入场动画

## 效果规格（两处统一）

- 数据首次上屏后，曲线**从左向右约 1.1 秒逐渐画出**（星数上升的曲线会自然呈现"爬升"感），而不是瞬间出现
- 渐变面积、终点标记、事件标注跟随曲线**延迟淡入**
- **重播时机**：每个仓库曲线首次上屏（缓存命中或网络首达）+ 洞察页切换范围（3m/1y/all）时；同范围刷新出新数据、头像晚到触发的重渲染**不重播**（避免进入页面后 1 秒内曲线画两遍）
- 尊重项目强制约定：读 `\.starcatReduceMotion`（系统减少动态 OR 设置内"关闭应用内动画"）→ 瞬切终态
- 洞察页"复制图片"导出的截图**永远是完整终态曲线**

## 改动 1：洞察页 Swift Charts 曲线

**`Starcat/Features/Insights/StarHistoryChartView.swift`**（无新文件）：

- 新增 `var animateEntrance: Bool = true` 参数、`@State private var revealProgress: CGFloat`、`@Environment(\.starcatReduceMotion)`
- 用 `.chartPlotStyle { $0.mask(alignment: .leading) { StarHistoryRevealMask(progress:) } }` 遮罩绘图区——曲线、地标点、网格线从左往右揭示；轴标签在绘图区之外不受影响、坐标轴全程稳定（符合"只用进度类动画、不位移"的现有约定）
- 文件内新增仓库首个带 `animatableData` 的 `StarHistoryRevealMask` Shape（按规范写"为什么 + 关键约束"级注释）
- 触发策略：`.onAppear` 启动（首次落点，以及调用点 `.id(range)` 导致的重建=范围切换）；`.onChange(of: model)` 仅在旧 model 为空（切仓库）时重播；`withAnimation(.easeInOut(duration: 1.1))` 推进 `revealProgress` 0→1
- 禁用态（reduceMotion / `animateEntrance == false`）effectiveProgress 恒为 1，首帧即终态、无闪烁

**`Starcat/Features/Insights/RepositoryInsightsView.swift`**（调用点 `starChart(isShareCapture:)`，约 L1612）：传 `animateEntrance: !isShareCapture`。离屏截图子树同样从 state=0 开始，但 effective=1，剪贴板必为完整曲线。现有 `.id(range).transition(.opacity)` 0.2s 淡入保留，与生长动画叠加不冲突。

## 改动 2：README 底部 WebView SVG 曲线

完全仿照现有 README 翻译入场动画（`prefersAnimatedEntrance` + Swift 侧 OR 门控 + JS 参数）的成熟模式：

1. **`Starcat/Features/Insights/ReadmeStarHistoryPreview.swift`**
   - `ReadmeStarHistoryRenderState` 增加 `prefersAnimatedEntrance: Bool`；`.empty`、骨架、清空均为 false
   - `applyIfVisible` 中以 `lastRenderedFingerprint == nil`（本次是本仓首张正式卡片）判定入场 → true；网络刷新、头像晚到的重渲染为 false
2. **`Starcat/Shared/Components/ReadmeWebView.swift`**
   - Coordinator 增加 `starHistoryReduceMotion`，`updateStarHistoryRenderState(_:reduceMotion:)` 镜像 translation 通路（`makeNSView` L374 / `updateNSView` L391 两处调用点都已持有 L335 的环境值）
   - JS 桥接改为 `window.starcatReplaceReadmeStarHistory(html, animate)`，`animate = state.prefersAnimatedEntrance && !starHistoryReduceMotion`
3. **`Starcat/Shared/Components/ReadmeStarHistoryDOM.swift`**
   - `configureStarHistory(host, animate)` 在 `layout()` 后调用 `playReveal()`：`polyline.getTotalLength()` 设 `stroke-dasharray/dashoffset` → 强制 reflow → CSS transition 释放为 0；面积/标注/标记设 opacity 延迟淡入
   - `transitionend` + `setTimeout` 双保险清理内联样式（离屏 WebView transition 可能停滞；残留 dasharray 会在后续 resize 重排 points 时裁剪曲线）
   - `layout()` 中"reveal 进行中且宽高真的变化"→ 立即跳终态（初次 ResizeObserver 回调尺寸未变，不会误杀动画）

CSS 不改（动画样式全部由 JS 内联、仅 animate=true 时设置）；本地化、数据库、`功能实现总览.md` 均不涉及（总览条目完成后仅在回复中起草、等确认再写）。
